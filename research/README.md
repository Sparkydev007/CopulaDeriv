# CopulaDeriv research workspace

Directory skeleton supporting the research-paper workflow. Contents are
generated by the dashboard's export buttons and offline experiment scripts.

| Subdirectory | Contents |
|---|---|
| `literature/` | Reading notes and bibliography sources for the copula/rainbow-option literature review. Not populated by code. |
| `dashboard_experiments/` (created under `copuladeriv/`) | JSONL experiment records written by CopulaDeriv Studio; non-durable on Streamlit Community Cloud — export. |
| `figures/` | Reproducible manuscript figures; see `copuladeriv/docs/research_figure_guide.md`. |
| `tables/` | Tables derived from exported CSVs (copula comparison, sensitivity, benchmarks). |
| `exported_results/` | Raw numerical exports (CSV/JSON) with metadata, as downloaded from the dashboard. |
| `manuscript/` | Research paper draft. |

Rules: a result stored here is either an exported *dashboard experiment* (has an
`experiment_id`), an *offline script result* (from `copuladeriv/python/experiments/results/`,
has an `experiment_id` keyed by configuration), or a synthetic example explicitly
labelled as such — synthetic examples must never be presented as research findings.
